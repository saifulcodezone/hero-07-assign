# 🛒 Bazar Dor

> Daily market prices at a glance.

A responsive web app to view today's prices of rice, lentils, oil, vegetables, fish, meat, eggs, and spices across 12+ markets in Bangladesh.

---

## 📖 Description

Bazar Dor shows today's prices, min/max/average rates, and daily change (%) for 33+ products from markets across Dhaka, Chattogram, Rajshahi, Mymensingh, Khulna, and Sylhet. Features Bengali-first UI, secure authentication, and a mobile-friendly layout.

---

## 🛠️ Technologies Used

- **Next.js 16** (App Router)
- **React 19**
- **Tailwind CSS v4**
- **BetterAuth** (Email + Google + GitHub)
- **react-hot-toast** — Notifications
- **lucide-react** — Icons
- **Hind Siliguri** — Bengali font
- **Vercel** — Deployment

---

## ✨ Key Features

1. **Live Price Ticker** — Infinite scrolling marquee with product, price, and ▲/▼ change.
2. **Top Risers & Fallers** — Today's top 6 gainers and losers on the home page.
3. **BetterAuth Authentication** — Email/password plus one-click Google and GitHub login.
4. **Bazar-wise Price Table** — Protected detail page with min/max/avg prices across 12 markets.
5. **Smart Bengali Sort** — Sort by price (low→high / high→low) with Bengali numerals.
